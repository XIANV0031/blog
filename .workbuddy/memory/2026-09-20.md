### 关键技术结论（已沉淀进 skill `hugo-github-pages-deploy` 第 4.8 节）

1. **Popular Airsoft 主图不能靠 DOM 定位** —— 正文由 JS 注入，
   抓 3 篇不同文章返回的 HTML 完全一样。必须按标题做**语义匹配**。
2. **「feed 顺序 ↔ 图片顺序」映射错配率 5/10**（把 KAC KS-1 配成 M29）。
3. **语义匹配的关键是「强信号词加权」**：品牌名 + 型号代号（含全大写串如
   `BLK`/`KS-1`/`MWS`）各 +12 分。纯长度加权只有 5/10，加权后 **10/10**。
   `Taiwan Gun: EMG Well Pro KAC KS-1` 从 39 分跳到 110 分，与次优（15）拉开决定性差距。
4. **封面比例必须强制归一化**：采集图比例跨度 0.56~3.81；
   用 `aspect-ratio: 16/9`（列表）+ `16/6`（详情）+ `object-fit: cover`。
   验证标准是「不同原始比例的图渲染后尺寸完全一致」——实测 1600×600 与 1000×714 同为 812×457。
5. **PaperMod 封面用 `absURL`，本地预览必 404** → 新建
   `layouts/_partials/cover.html` 覆盖，把 `absURL` 改 `relURL`。
6. **给 Windows 版 Python 传路径必须转格式**：MSYS 路径 `/d/blog-hugo/...`
   会报 `FileNotFoundError`。加 `winpath()`（走 `cygpath -w`）。
